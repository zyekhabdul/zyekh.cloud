## How to test (quick)
1. Add token: create or update `.env.local` with `VITE_GITHUB_TOKEN=your_token_here`.
2. Install dependencies (if needed): `npm ci` or `npm install`.
3. Run dev server: `npm run dev` and open `http://localhost:3000`.
4. Run linters: `npm run lint:eslint` and `npm run lint:fix`.
5. Build preview: `npm run build` then `npm run preview`.
